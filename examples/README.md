# Example outputs (samples)

**These files are samples, not real data.** The companies in them (Acme Analytics, Northwind Metrics and Globex Insights) are fictional. They were generated with Outflank's own digest and battlecard code, so the format matches what a real run writes to `data/`. The analysis text was written by hand to show the style.

- [`digest-baseline.md`](digest-baseline.md): the digest from a first run, which creates the baselines and battlecards.
- [`digest-weekly.md`](digest-weekly.md): a weekly digest with one material change (including a keyword trigger) and two minor changes.
- [`battlecard.md`](battlecard.md): a battlecard after its first weekly update.

Links in the samples point to a made-up GitHub repo (`you/my-outflank`), as they would inside GitHub Actions.
